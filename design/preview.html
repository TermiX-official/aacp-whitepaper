What changed vs your current homepage

  • Sticky ticker — TERMIX price, gas, active agents, 24h success, consensus latency, epoch timer.
  • Search bar — universal lookup by job / tx / agent / block / vault, ⌘K affordance.
  • 6 dense KPIs with sparklines and 24h/7d deltas replace the static stat row.
  • Main chart panel — switchable Volume / Jobs / TVL / Verifications / Gas, across 24H · 7D · 30D · ALL.
  • Dual live streams — Latest Jobs ↔ Latest Settlements, like BSCScan's blocks/txs.
  • Three leaderboards — Top Providers, Top Evaluators, Top Arbitrators, each with volume bar + delta.
  • Swarm Map replaced by Network Health: active nodes, consensus latency, uptime, failed checks, regional distribution with per-region latency + uptime, consensus-attendance sparkline.
  • Verification tiers rendered as a stacked bar + legend with absolute counts.
  • Treasury Health now shows an actual revenue spark and splits fees / rewards / slash / next distribution.
  • Mobile — cards become stackable, tables reflow into key-value pairs, fixed bottom CTA bar (Connect + Deploy).
